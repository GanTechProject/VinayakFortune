# Cycle Artifacts — Archived Convention

**Status:** Archived 2026-07-27 (closes [issue #38](https://github.com/GanTechProject/VinayakFortune/issues/38)).
**Decision:** Stop the per-cycle "commit-script-and-audit" follow-up PR pattern.

## Why archived

The "Option 3 cycle" follow-up PR existed to record the DELETE/PUT branch-protection dance that was required while the OAuth scope block on `.github/workflows/*` was active. Every merge required:

1. DELETE on branch protection,
2. direct push to `main` to land the workflow fix,
3. PUT to restore branch protection,
4. follow-up PR committing the cycle's bash script and audit JSON.

Path 1 (PR #42, merged 2026-07-21) eliminated the DELETE/PUT dance by setting `required_approving_review_count: 0` on live branch protection. After Path 1, merges flow through real CI: the cycle script is no longer run, the DELETE/PUT is no longer needed, and the audit JSON is auto-generated by GitHub Actions check-runs rather than by a hand-written cycle script.

Subsequent merges — PRs #43, #44, #45, #46, #47, #48, #49, #50 — all went through real CI with no cycle, no DELETE/PUT, and no audit follow-up. The convention had structurally paused; this document records that pause as a deliberate archive.

## What replaced the cycle

Modern audit trail comes from three sources:

- **GitHub Actions check-runs** — every CI run on every commit is recorded in the GitHub UI/API (see `gh api .../commits/<sha>/check-runs`).
- **Branch protection audit log** — live API changes are visible via `gh api .../branches/main/protection`.
- **Conventional-commit messages** — PR titles carry the `feat:`/`fix:`/`chore:`/`docs:`/`refactor:`/`perf:`/`test:`/`style:`/`revert:` prefix that release tooling reads for version bumps and changelogs.

The 3rd-party bash cycle script added no information that these three sources don't already provide.

## What to do if a new OAuth-style block appears

If a similar workflow-scope block ever returns, the resolution path is:

1. Surface to the conductor immediately (the human-only unblock).
2. Do NOT bring back this archived convention as-is — a fresh cycle script should be designed around the new block, not copy-pasted.
3. The new cycle's audit + script would be a fresh start, not a continuation.
